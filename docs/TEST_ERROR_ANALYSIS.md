# 测试错误分析与面试要点

2026-10-23。个人项目／模拟业务。以下来自已完成的30条测试，不再用于修改本次固定方法。引用为不含姓名、精确地址的短片段；完整证据私有保存。人工只有一位且有AI辅助指南复核，不能声称双人一致。

|现象|匿名片段|人工判断|实际预测|解释假设|
|---|---|---|---|---|
|否定与混合|TS021：“pequeño pero cómodo para 2 personas, lamentablemente no tiene elevador”|设施混合|规则中性；AI不确定|缺电梯与舒适度的正反信息未被有效整合。|
|转折|TS004：“no le entra mucha luz, pero…”；“tampoco pasas frío”|设施混合|两方法均未提及|采光、空间与保暖表达覆盖不足，转折并未被理解。|
|整体赞扬掩盖局部投诉|TS008：“el aire acondicionado que tenia un ruido extraño”|设施负面|规则提及但情绪不确定；AI正面|局部设施问题可能被整体好评影响，不能将整体情绪当每个主题情绪。|
|缺少某种功能|TS029：“la tele no era SmartTV”|设施负面|两方法均未提及|设备词汇、功能缺失的覆盖不足。|
|含糊表达|TS006：“en un sector tranquilo”|噪音不确定|规则正面；AI未提及|tranquilo未必描述声音。此人工不确定行按预定协议排除出该主题评分，单列而不硬判对错。|

原因仅为从文本和方法结构提出的解释，未进行消融实验。没有用这些错误更新本次词典、原型或阈值。完整差异在data/stage4/compact/test_disagreements.json，仅供本地追溯。

## 可以在面试中怎样讲

“我把真实公开评论按房源及近重复文本分组隔离，先做试标和开发，再在固定方法后做30条留出测试。人工负担使第一版由约300条缩为80条，我保留了范围变化记录。20条开发揭示了词典漏词和句子级情绪混淆，第一版保留两种原始基线进行诚实比较，没有声称调参提升。”

“测试中设施负面内容有5条，规则识别0条、AI识别1条；噪音负面仅1条，规则识别、AI漏掉。其余四主题无负面正例，所以不能评估它们检出投诉的能力。即便某项Precision为100%，也可能只预测对了1条，必须同时报告支持数与召回率。”

“因此后续看板只能把模型标签作为待核查线索，不能将全量预测比例当真实投诉率，更不能把评论数当订单、推算收入提升。未来可扩充设备同义词、改善否定及主题级情绪，但改进后需新的留出测试，不能在已看过的测试上反复调参后宣称泛化。”

完整P/R/F1、TP/FP/FN、正例数和弃答见TEST_EVALUATION.md及outputs/stage4/evaluation/metrics.json。小于10个人工正例的类别全部只作描述。人工安全/设施/模糊声环境等16项修订由用户确认，原始标签保留；报告应明确这是AI辅助指南复核后的单人参考标注，而不是未经协助的完美金标准。
