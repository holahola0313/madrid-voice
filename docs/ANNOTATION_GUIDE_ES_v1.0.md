# Madrid Voice — Guía de anotación en español

Versión: **v1.0, fijada para desarrollo y test**, 17 de octubre de 2026. Proyecto personal y escenario de negocio simulado. Las aclaraciones del piloto se incorporan al final. Anota sin consultar predicciones.

## 1. Objetivo y unidad

Lee una reseña completa y etiqueta seis aspectos por separado. Describe lo que expresa la persona, sin verificar si el hecho ocurrió y sin inferir nacionalidad, número de reservas o causas. Una reseña puede mencionar varios aspectos. Cada combinación reseña–aspecto recibe una sola etiqueta final.

Trabaja sin consultar las predicciones de las reglas o de la IA. Las celdas vacías significan «sin anotar», no «aspecto ausente». No uses otra IA para rellenar las etiquetas humanas. Puedes consultar un diccionario para entender una palabra; si la duda persiste, anótala.

## 2. Primero, el idioma de la reseña

En la hoja «评论与进度», selecciona:

| Valor     | Criterio                                                                                             |
| --------- | ---------------------------------------------------------------------------------------------------- |
| es        | Español predominante; préstamos como check-in, wifi o host no lo convierten automáticamente en mixto |
| mixto     | Hay fragmentos sustanciales en español y en otro idioma; explica qué parte no puedes interpretar     |
| otro      | El contenido útil está principalmente en otra lengua                                                 |
| incierto  | No hay contexto suficiente para decidir la lengua                                                    |
| sin_texto | Solo símbolos, números u otro contenido sin significado interpretable                                |

Para es y mixto, etiqueta los seis aspectos si puedes interpretar el contenido. En mixto, una parte no comprendida debe conservarse como duda, sin inventar una traducción. Para otro, incierto o sin_texto, escribe el motivo en la hoja de reseñas y deja las seis etiquetas temáticas vacías. Se revisarán antes de incluir la reseña en la evaluación.

## 3. Los seis aspectos

| Aspecto          | Incluye                                                                                                                 | Límites                                                                                                                |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Limpieza         | Suciedad, polvo, manchas, higiene, sábanas limpias, insectos o moho relacionados con condiciones sanitarias             | No deduzcas limpieza a partir de «bonito», «nuevo» o «cómodo»                                                          |
| Ruido            | Sonidos, aislamiento acústico, ruidos de vecinos/calle, tranquilidad vinculada a dormir o al nivel sonoro               | «Barrio tranquilo» sin contexto acústico puede ser seguridad o ambiente: explica la ambigüedad                         |
| Entrada / salida | Check-in/check-out, llaves, acceso inicial, instrucciones, horarios de llegada/salida y esperas para entrar             | La cercanía al metro es ubicación; la rapidez de una respuesta también puede ser comunicación                          |
| Instalaciones    | Cama/colchón, ducha/agua caliente, wifi, calefacción/aire, cocina/equipamiento, ascensor y funcionamiento/mantenimiento | Un baño sucio es limpieza; etiqueta instalaciones además solo si se comenta funcionamiento, disponibilidad o comodidad |
| Comunicación     | Respuestas, mensajes, claridad, trato, amabilidad y ayuda del anfitrión o personal                                      | El nombre del anfitrión por sí solo no indica una evaluación; el barrio «bien comunicado» se refiere a ubicación       |
| Ubicación        | Distancias, acceso al transporte, centralidad, entorno, seguridad del barrio y conveniencia geográfica                  | No deduzcas que lejos es malo: puede ser una preferencia positiva; desperfectos interiores no son ubicación            |

Puedes marcar dos aspectos si cada uno cuenta con apoyo. Por ejemplo, una demora en recibir por mensaje las instrucciones de acceso puede afectar entrada y comunicación. No fuerces una categoría para temas fuera del alcance, como precio o relación calidad-precio: registra el tema en notas si es útil.

## 4. ¿Se menciona el aspecto?

| Valor    | Significado                                                                     |
| -------- | ------------------------------------------------------------------------------- |
| presente | Hay una referencia explícita o una implicación suficientemente clara al aspecto |
| ausente  | La reseña no aporta información sobre ese aspecto                               |
| incierto | Hay una posible referencia, pero falta contexto para asignarla con seguridad    |

La valoración general «todo perfecto» no significa que todos los aspectos estén presentes y sean positivos. Una mención puede ser neutral. Tampoco debes etiquetar como ausente un problema expresado indirectamente si el aspecto es claro, por ejemplo una imposibilidad de dormir causada por sonidos.

## 5. Sentimiento del aspecto

| Valor     | Criterio                                                                                                  |
| --------- | --------------------------------------------------------------------------------------------------------- |
| positivo  | Expresa satisfacción, una ventaja o ausencia explícita de un problema                                     |
| negativo  | Expresa insatisfacción, una desventaja, fallo o carencia no deseada                                       |
| neutro    | Describe el aspecto sin valoración positiva ni negativa                                                   |
| mixto     | Hay contenido positivo y negativo sobre **el mismo aspecto** dentro de la reseña                          |
| incierto  | Se menciona el aspecto, pero la valoración es ambigua, irónica sin contexto suficiente o no interpretable |
| no_aplica | Solo cuando la mención es ausente                                                                         |

Combinaciones: ausente + no_aplica; incierto + incierto; presente + positivo/negativo/neutro/mixto/incierto. No uses no_aplica como sinónimo de duda.

No resuelvas contradicciones tomando automáticamente la última frase. Si hay dos valoraciones opuestas del mismo aspecto, conserva mixto salvo que el texto corrija expresamente la primera afirmación. Una experiencia positiva de limpieza y una negativa de ruido no forman dos etiquetas mixtas: limpieza es positiva y ruido negativo.

## 6. Negación, contraste y ejemplos de práctica

Los siguientes ejemplos son **inventados para explicar la guía**. No son respuestas de las reseñas piloto ni datos de evaluación.

| Ejemplo didáctico                                                | Decisión                                                                                                                    |
| ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| «El piso no estaba limpio.»                                      | Limpieza presente, negativo                                                                                                 |
| «No había ruido y dormimos bien.»                                | Ruido presente, positivo                                                                                                    |
| «No solo estaba limpio, también era cómodo.»                     | La expresión no solo no niega la limpieza; limpieza positiva. La comodidad necesita contexto para asignarla a instalaciones |
| «La habitación estaba limpia, pero las sábanas tenían manchas.»  | Limpieza presente, mixto; copiar ambas partes                                                                               |
| «La cama era cómoda, pero se oía el tráfico toda la noche.»      | Instalaciones positivo y ruido negativo; no mixto en cada aspecto                                                           |
| «Hay cocina y ascensor.»                                         | Instalaciones presente, neutro                                                                                              |
| «El anfitrión respondió, aunque no sé si entendió mi consulta.»  | Comunicación presente; valoración posiblemente incierta, con nota que explique la duda                                      |
| «Está lejos del centro, justo lo que buscábamos para descansar.» | Ubicación presente, positivo según la preferencia expresada; no aplicar automáticamente lejos=negativo                      |
| «No estaba limpio: estaba impecable.»                            | Si el contexto es una intensificación inequívoca, limpieza positiva; no invertir mecánicamente por no                       |
| «Genial, otra noche sin agua caliente.»                          | Instalaciones negativa si la ironía es clara por el contexto; si no, incierto                                               |
| «La ubicación, bueno…»                                           | Ubicación presente, incierto; no inventar una queja                                                                         |
| «La entrada es a las 15:00.»                                     | Entrada presente, neutro                                                                                                    |

## 7. Evidencia y notas

Para presente o incierto, copia una frase breve de la reseña original que respalde la decisión, respetando palabras y puntuación. No copies un resumen, traducción ni explicación tuya en la columna de evidencia. Para mixto, conserva las dos partes; puedes separarlas con **`||`**. Un único fragmento que contenga ambas valoraciones también sirve.

Para ausente, deja evidencia vacía: no existe una cita que pruebe la ausencia. Para cualquier etiqueta incierto, explica la duda en notas. No incluyas una calificación general como evidencia de un aspecto específico si no lo sustenta.

Los textos conservan información pública del origen y podrían mencionar nombres. Úsalos solo en el archivo local de anotación; no publiques el libro o capturas. No cambies el texto fuente ni los identificadores MV. La anonimización para una presentación pública será una tarea separada.

## 8. Flujo de anotación

1. Escribe tu seudónimo habitual y la fecha de la sesión en YYYY-MM-DD.
2. En desarrollo, empieza por DV001–DV020 y confirma el idioma.
3. Rellena las seis filas de cada reseña y conserva citas exactas.
4. Guarda dudas en notas y el archivo al terminar cada bloque. No necesitas ejecutar Python.
5. El test se entregará después de completar desarrollo y fijar los métodos. No se usará para ajustar reglas o umbrales.

## 9. Limitaciones de la anotación

Una sola persona no permite estimar acuerdo entre anotadores. La consistencia interna puede mejorarse revisando ejemplos y registrando cambios, pero no equivale a una segunda opinión independiente. Un test de unas 100 reseñas puede contener pocos negativos de algunos temas: se mostrarán los soportes y las métricas indefinidas o inestables, sin rellenarlas con valores inventados.

## A. Aclaraciones fijadas tras la revisión del piloto

### A1. Instalaciones frente a valoración general

Incluimos equipamiento, funcionamiento, mantenimiento y condiciones físicas de uso: tamaño, distribución, iluminación, ventanas, acceso por escaleras, comodidad explícita de la habitación o vivienda, y disponibilidad de artículos necesarios para la estancia. No se debe inferir una causa técnica que el texto no explique.

Son referencias suficientes «bien equipado», «todo funcionaba», «habitación espaciosa», «cama cómoda», «apartamento cómodo», «nuevo» referido al estado físico y «cuenta con todo lo necesario». Se distingue una comodidad física explícita de una satisfacción general con el viaje.

No bastan por sí solos «buen alojamiento», «magnífico espacio», «precioso», «todo genial», «me parece perfecto» o «tal como se describe». La decoración o belleza por sí solas quedan fuera del alcance de este aspecto. «Limpio y ordenado» no debe crear automáticamente una segunda etiqueta de instalaciones.

Una dificultad con ventanas, iluminación, espacio o escaleras cuenta si el texto la valora como tal. Si el mismo aspecto contiene comodidad y una desventaja explícita, se usa mixto y se guardan evidencias de ambas partes. Este alcance se mantiene fijo en desarrollo y test.

### A2. Tranquilidad y ruido

«Zona tranquila» sin contexto acústico o de descanso puede expresar ambiente o seguridad. En estos casos se usa mención incierto, sentimiento incierto y una nota. El contenido sobre ubicación o seguridad se puede etiquetar por separado si es claro.

Una referencia explícita a sonidos, silencio, aislamiento acústico o descanso afectado por sonidos permite decidir presencia. El contexto «descansar con tranquilidad», sin indicios contrarios y relacionado con el entorno, puede respaldar una lectura acústica; si hay duda, debe conservarse.

### A3. Aceptar una desventaja no crea una valoración positiva

Mixto exige contenido favorable y desfavorable del mismo aspecto. Justificar o aceptar el ruido por la localización no implica valorar positivamente el sonido. Si el ruido se presenta como coste o inconveniente, negativo; si solo se describe sin valoración, neutro. Se debe leer la reseña completa y conservar la duda cuando proceda.

Una incidencia inicial seguida de una resolución valorada positivamente puede ser mixta en el proceso de entrada. No se aplica la regla mecánica «pero = mixto».

### A4. La evidencia debe contener la valoración

Una palabra como «instalaciones» demuestra una mención, pero no por sí sola una valoración positiva. Si un adjetivo al principio de la frase modifica varios aspectos, se conserva la frase que contiene ese adjetivo. Para mixto deben quedar representados ambos polos en una o varias citas exactas, separadas por ` || `.


La revisión humana del piloto incorporó sugerencias de IA. Las decisiones originales y revisadas se conservan. No son dos anotadores humanos independientes. Cualquier cambio posterior de criterios requiere otra versión y revisar las etiquetas afectadas.
