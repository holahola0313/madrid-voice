# Madrid Voice 评估协议v1.0

固定日期2026-10-17。个人项目、模拟业务。人工指南v1.0；本文件定义后续计算方式，**目前没有测试结果**。

## 样本、隔离和用途

来源为Madrid同一快照、原10,000条处理上限内的3,763条西语候选，评论时间2025-09-01—2026-08-31。标注选择先做规范化完全重复及字符三元组Jaccard>=0.85近重复分组（长度>=40字符），与同房源关系取传递连接。共选300个不同组各一条，30试标、170开发、100测试。270条储备按种子20261017打乱后拆分，不按标签或预测挑选，也不为补稀少类别重新抽测试。

试标包含已探索样本，且由用户在AI解释后修订，仅用于指南和开发，不能作为独立测试。开发与测试均避开此前AI阅读过42条样本所关联的组，三部分房源、文本簇及连接组不得交叉。划分清单、指南、配置、来源及原方法指纹保存在formal_split_manifest.json。近重复隔离不保证识别所有语义改写，也不证明被合组评论情绪相同。

这是每组最多一条的评估样本，不是对全市评论的等概率抽样。试标还有限长和有目的选择，不能用其标签分布估计全市问题率或经营收益。只有一位人工标注者，不能报告标注者间一致率。

## 开发和测试门槛

先发放170条开发集，允许分批填写、讨论指南和改进方法。每次保留原提交、修订、方法版本和证据。若改动标签定义，必须新版本指南并复核已标开发数据，不能暗改当前v1.0。

开发集完成后，固定规则词典、AI原型/阈值或训练参数、代码、依赖、模型、指南及预测文件哈希，并生成测试方法冻结记录。第三阶段原始版本保留；改进必须新版本。仅在这些条件完成后发放100条测试文本，用户独立标注，不看模型答案，不让AI代填。测试标签不能反过来改规则或阈值。对测试方法再改进时，需新的独立留出集才能再次宣称独立评估。

当前只准备测试ID，不发放测试工作簿、不计算指标。空白、部分完成、未经语言复核、证据不合法或重复键不能自动当金标准。若有人工作业不完整，只报告进度及问题，不输出性能分数。

## 指标定义

统计单元是“评论×主题”。对同一测试范围、同一人工指南和各固定方法版本比较。每条评论每主题每方法版本最多一行。连接前后独立键数必须一致，不把六主题行数当评论数。

| 任务 | 纳入范围 | 正例/类别定义 |
|---|---|---|
| 六主题提及 | 人工present或absent；人工uncertain排除并单列 | 每主题present为正例 |
| 六主题负面内容 | 人工absent；或人工present且情绪为positive/negative/neutral/mixed；人工不确定排除 | 每主题negative或mixed为正例，另报告两者各自支持数 |
| 六主题逐类情绪 | 人工present且情绪明确的行 | 每主题positive、negative、neutral、mixed分别做一对其余 |

“负面内容”包含mixed，不能称纯负面；纯negative与mixed的逐类结果分别保留。模型漏掉主题或给uncertain时，不剔除这条真实正例，会计相应标签的FN；同时单列模型弃答数量和比例。预测uncertain不算预测正例；不能通过仅评估模型有把握的行提高召回率。

TP=人工与模型都判为该正类，FP=模型判为该类而人工不是，FN=人工是该类而模型未判为该类。

- Precision=TP/(TP+FP)。
- Recall=TP/(TP+FN)。
- F1=2TP/(2TP+FP+FN)。

某公式分母为0时该指标为NA，不补0或编造分数。逐标签列出纳入行数、人工正例数、模型正例数、TP/FP/FN和人工/模型不确定数。至少1条有效记录才展示结果行；人工正例不足10条标为稀少类别，仅描述，不判断方法优劣。无人工正例的类别即使因误报得到可计算的F1，也明确写“无真实正例，不能评估检出能力”。汇总指标只作辅助，说明纳入哪些类别，不能隐藏支持数。

语言为es或可理解的mixto可纳入；otro、incierto或sin_texto须说明并复核，不自动当六主题全absent。混合语言里无法解释的内容保留不确定。最终评估例数可能少于100，按实际数量报告，不为凑满样本随意补抽。

## 错误分析与结论

指标之外，展示否定、转折、同主题正负混合和含糊表达的真实错误案例，含匿名原文证据、人工标签、各方法预测和原因假设。案例只在测试完成后选，不能用于重新调同一测试上的参数。AI阅读不构成第二个人工标注者；证据一致性检查只保证可追溯，不保证判断正确。

若100条测试中负例很少，必须如实说明评估有限，不能把总体正面占比、软件测试通过率或模型间一致率当准确率。评论数不是订单数，可订状态不是入住天数；所有运营建议仍需实际分析支持，不能作无依据的因果或收入提升结论。
